# Tests

- **A test waits for what it expects, never on the clock,** with one deadline that only a broken build reaches (`WITHIN`): on what it watches announcing a change (`Changes`, or `Changes::until` in an async test), or on a future (`within`). A "nothing happened" check comes after something later did, never after a sleep. ([testing](/crates/waos-headless/src/testing.rs))
- **A sleep in a test fails clippy.** Code that sleeps for a reason of its own says why in an `#[allow]` beside it; what nothing announces yet waits in `poll_until`, each use naming what would let it wait on a change. ([clippy.toml](/clippy.toml))
- **A stand-in for something slow outside holds until the test lets it go** (`Hold`), so a test sees the state that lasts while a compile or a download runs; the app's installs hold with `HeldCompiler`. ([testing](/crates/waos-headless/src/testing.rs), [test_installs](/apps/waos/src/logic/test_installs.rs))
- **A test moves the engine's time instead of waiting for it,** so a freeze's delay passes at once. ([lifecycle](/crates/waos/src/lifecycle/mod.rs))
- **A test of the app turns the app until what it waits for has happened,** each turn woken by one of the app's tasks or by a frame, a window or a timer due on the test's own clock, never by a timer of the test's. ([test_turns](/apps/waos/src/state/test_turns.rs))
- **The engine's tests run side by side in one process,** on a headless shell where the test plays every part of the platform (the user's answers, the clipboard, dialogs, cameras), each part announcing what it was told on the shell's changes, each test reading only its own shell and its own apps' output. ([test_shell](/crates/waos/tests/all/test_shell/mod.rs))
- **What is costly is made once for a run:** the test apps are built and compiled once (`waos_test_programs`), and an install compiles each component's content once (`TestCompiler`), which a test's WaOS is set up with (`Setup::for_tests`). ([programs](/crates/waos/tests/programs/build.rs), [test_installs](/apps/waos/src/logic/test_installs.rs), [startup](/apps/waos/src/logic/startup.rs))
- **A store a test needs but does not test is kept in memory** (`SettingsInMemory`, `SourcesInMemory`, `ActivityInMemory`). ([services](/crates/waos-services/src/lib.rs))
- **Each system tests what concerns it,** listed in one place. ([ci.yml](/.github/workflows/ci.yml))
