# image-codecs

A program that decodes and encodes images through the system's codecs, and what the tests read an image's way through WaOS from: it says the formats the codecs decode and encode, as `formats: decodes image/jpeg, image/png; encodes image/png`, and `hardware codecs: none` where the system has none; then, for each image listed in its `/data/sources`, one a line, a path it opens as a file, or after `bytes `, a file it reads and opens from its bytes, it says what the image says of itself, as `source: image/jpeg 32x48, pictures: still, turned quarter-turn`, an animation's frames and how often it plays as `pictures: 2 frames of 100ms, 200ms, played 3 times`, and a document's pages, each its size, as `pictures: 2 pages of 3x2, 2x5, primary 1`, and when, with what, how and where it was taken, as `source: taken 2024-05-01 10:20:30 +02:00`, `source: camera Waft Test Camera, lens Test Lens`, `source: exposure 1/120 s, f/1.8, ISO 200` and `source: location 48.85083, -2.29500, 35 m`, each `none` where the file says nothing; the picture it shows, a still image's one, an animation's first or a document's primary page, decoded into its own memory, no larger than 16 by 16, by its size, its layout and the colours at its top and its bottom, as `source: pixels 11x16 rgba8 premultiplied, red above blue`; where the system can, decoded whole into a hardware buffer, saying what the buffer can be used for (`hardware-buffer.usage`), whose pixels it reads back, as `source: hardware buffer 32x48 for gpu-sampled, composer-overlay, cpu-read, read 32x48 bgra8 premultiplied, red above blue` on Apple's systems; and both encoded again, the pixels as PNG and the hardware buffer as JPEG, each opened again by its size, as `source: encoded image/png opens 11x16`; or why a step failed, as `source: open failed (not-found: why)`. Then it ends. Where the system has no image codecs it says `image codecs: none`. Its tests write the sources, and a photo at `/data/photo.jpg`, before it starts.

- **Takes:** `wasdk`.
- **Provides:** a component, `target/wasm32-wasip3/debug/image-codecs.wasm`, from `cargo build -p image-codecs --target wasm32-wasip3`.
- **Used by:** the engine's tests (`crates/waos/tests/all/image_codecs.rs`) and the app's (`apps/waos/src/state/image_codecs.rs`), through `crates/waos/tests/programs`.
