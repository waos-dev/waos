# waft-menus

An Waft app with menus: a window with a text field holding a line, under a `PlatformMenuBar` of an app menu, File with Greet, Open…, which asks for a text file in the platform's dialog and prints it, Open Link, which opens a web page in the app the system picks, and Notify, which asks its user to allow notifications and posts a greeting with a button, and Edit's Copy and Paste, the platform's; and a `PlatformTrayIcon`, a dot, whose menu has Open, shown on the platform's own trigger. Its text field leaves ⌘C, ⌘X and ⌘V to a host with a menu bar and acts on the host's Edit commands. Clicking the icon opens a context menu at the window's corner. It hears what its user opens with it and what they do to its notifications. It prints `field: focused` once the field has the focus, each change of the field's text as `field: text`, each choice and what the user does to the icon as `what: result`, each file opened with it as `opened with it: path: text` and each link as `opened with it: link`, and each click on its notifications as `notification: id action reply`. What the engine's tests run to see Waft's menus, Edit's commands, file dialogs, opener, notifications and open requests reach a program through `wasdk-adapter-waft`, and what a user tries WaOS's menus for a program in.

- **Takes:** `wasdk-adapter-waft`; Waft's `waft-widgets` (the app, its window, its menu bar, its tray icon and the field's text), `waft-cupertino` (the page and the text field), `waft-embedder` (the platform's context menus, file dialogs, opener and notifications) and `waft-foundation` (the app, which hears what is opened with it and the clicks on its notifications), from Waft's checkout beside this one; `wasdk`, for the entry.
- **Provides:** a component, `target/wasm32-wasip2/debug/waft-menus.wasm`, from `cargo build -p waft-menus --target wasm32-wasip2`.
- **Used by:** the engine's tests (`crates/waos/tests/all/waft_menus.rs`), through `crates/waos/tests/programs`; whoever runs it in WaOS.
