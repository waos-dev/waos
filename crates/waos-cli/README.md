# waos-cli

`waos`, the command for writing apps: create, build, install, launch, attach, package, and drive a running app (screenshots, input, inspection). Docs: [waos.app/docs](https://waos.app/docs).

`waos devices`, `waos pair <device>`, `waos unpair <device>`, and `--device <name>` (or `WAOS_DEVICE`) on any command: reach a paired device's WaOS across the network.
