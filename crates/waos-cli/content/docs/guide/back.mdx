---
title: Back
description: Go back within the program when the user asks, while it has somewhere to go.
---

A phone's Back, its back button or gesture, goes back within a program while the program says it can, and is the system's own otherwise. A program says so in advance on its view, and hears Back only while it does: it runs behind the interface, so it cannot be asked on the spot. A view starts not handling Back.

## With wasdk

```rust
// on a page with one to go back to
view.set_handles_back(true);
// ViewEvent::PopRoute arrives on view.events(): go back a page, and on the first again
view.set_handles_back(false);
```

## With Waft

Nothing to write. Waft's app says whether one of its navigators has a route to pop, and a Back pops it, as `Navigator.maybePop` does in Flutter.

## Where it's missing

On a desktop nothing sends Back. On Android, while a program does not handle it, Back sends the program's task to the background, the program running on. Where the user has WaOS show programs in its own tabs, Back is WaOS's: it closes the tabs' overview, leaves the program for the home with the program running on in its tab, and on the home is the system's.
