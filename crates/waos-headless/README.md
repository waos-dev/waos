# waos-headless

A screen with no display for the engine: one screen, each program's request for a view given one at once, in a window filling the screen or in none as a phone's deck shows a tab, focused and in sight; its frames refreshed by a thread of its own, as soon as the engine asks or a set time after; and each view keeping the picture presented last until the next replaces it, which the engine reads back for a screenshot.

- **Takes:** a `Display`, the screen's size in physical pixels, its scale and whether views come in windows; `Refreshes`, when the screen refreshes once asked (`WhenAsked` for a test, `Every(interval)` for a program animating on a server); the `Prompts` its shell asks questions of; the engine it reports refreshes to (`attach`).
- **Provides:** `HeadlessScreen`, whose `shell` is the engine's `Shell` with this screen's placement and refreshes and every other part none, for its maker to plug in, real or a test's own; `screen`, the screen as `PlatformState` lists it; and `add_view`, a view given as the screen gives one, for a test that places one itself. `SCREEN`, the screen's id.
- **Used by:** the WaOS app's `waos --headless` (`headless_entry`), which plugs in the real questions and pickers, and the app's tests that draw (`logic::test_engine::drawing`). Its behaviour is tested through them: it does nothing without an engine and a running program. The engine's own tests move onto it next (`docs/proposals/2026-11-22-tests-without-the-clock.md`, step 5).
