# waos-headless

A headless shell: the windowing parts of the engine's shell over one screen with no display. Each program's request for a view is given one at once, in a window filling the screen or in none as a phone's deck shows a tab, focused and in sight; frames are refreshed by a thread of the shell's own, as soon as the engine asks or a set time after; each view keeps the picture presented last until the next replaces it, which the engine reads back for a screenshot; and what the engine told each view and window is kept, as a window system knows its windows.

- **Takes:** a `Display`, the screen's size in physical pixels, its scale and whether views come in windows; `Refreshes`, when the screen refreshes once asked (`WhenAsked` for a test, `Every(interval)` for a program animating on a server); the `Prompts` its shell asks questions of.
- **Provides:** `HeadlessShell`, whose `shell` is the engine's `Shell` with this shell's placement and refreshes and every other part none, for its maker to plug in, real or a test's own; `screen`, the screen as `PlatformState` lists it; `views` and `view(index)`, the views it gave, each a `HeadlessView`: the engine's view, whether the program handles Back, how many pictures it was handed and the layers handed with the last, the kind of text the program edits in it, and its `HeadlessWindow`, with the window config it was asked for, its title, its size limits and whether it is maximized or minimized, as the program last set them, and how many moves from a press it asked for; and `add_view`, a view given as the shell gives one, for a test that places one itself. Closing a window takes its view away, as a window system's does. `SCREEN`, the screen's id.
- **Used by:** the WaOS app's `waos --headless` (`headless_entry`), which plugs in the real questions and pickers, and the app's tests that draw (`logic::test_engine::drawing`); the engine's own tests next (`docs/proposals/2026-11-22-tests-without-the-clock.md`, step 5). It reaches its views only weakly, so it keeps nothing of a view the engine let go of.
