# waos-permissions

What the user lets each WaOS app use, and the questions being asked of the user now, as one domain: the settings and the answers the user gave, kept in a store it is handed (WaOS's settings files, or memory in a test); each app's grants, which the engine checks and waits on, asking the user through the prompts it is handed, once however many wait; and the one list of what is asked now. It follows the package manager's record, and knows nothing of the engine, Waft or UI.
