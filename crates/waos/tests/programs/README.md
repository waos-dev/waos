# waos-test-programs

The example programs the engine's tests run, built as components by this crate's build script, so `cargo test --workspace` needs no step run by hand first. The build script runs cargo for `wasm32-wasip3` into a target directory of this crate's own, under its `OUT_DIR`, so it does not wait on the workspace build's lock, with line tables as the programs' only debug information of their own (`CARGO_PROFILE_DEV_DEBUG=line-tables-only`), which a trap's backtrace names files and lines from, and writes the path of each program as a constant: `SURVEY`, `FOREVER`, `TRAP`, `TRIANGLE`, `COMPOSITION_LAYERS`, `FONTS`, `GALLERY`, `TWO_WINDOWS`, `PERMISSIONS`, `FILES`, `FILE_ESCAPES`, `NETWORK`, `FETCH`, `TRUST`, `CLIPBOARD`, `COPY_PASTE`, `MENUS`, `WAFT_MENUS`, `SOUND`, `TONE`, `FILE_DIALOGS`, `OPENER`, `NOTIFICATIONS`, `MACHINES`, `FILE_WATCHING`, `MEDIA_PLAYERS`, `MEDIA_ASSETS`, `IMAGE_CODECS`, `HARDWARE_BUFFERS`, `VIDEO_FRAMES`, `CAMERAS`, `NOTES`, `VIDEO_PLAYER`, `INPUT`, `BACK`, `WAFT_BACK`, `WAFT_IMAGE`, `WAFT_TIME`, `WORKERS`, `INSPECT`; `INCOMPATIBLE`, the one component no build makes, written by hand as text beside this README (`incompatible.wat`), which wasmtime compiles as it does a binary: it imports `wasdk:platform/system` with an `operating-system` of one case less than the engine serves, as a program built for another version of the interface does; `IMPORTS_INSPECT`, written by hand too (`imports-inspect.wat`), which imports an interface of `wasdk:inspect` and nothing else, as a program asking for the inspector role does; and `CODE_CACHE`, a folder beside them, under its `OUT_DIR`, where the tests' engines keep the code compiled from them, so each program is compiled once for each build of it, not once for each test that runs it. A test that runs a copy of a program, at a path of its own, keeps that copy's code in a cache of its own instead, since the cache names its files after the path compiled. It is built again when `examples/`, `sdk/` or `wit/` change, or the crates of Waft's checkout beside the workspace, which the gallery, two-windows, copy-paste, waft-menus, waft-back, waft-image, waft-time, notes and video-player are built from. This is how wasmtime builds its own test programs.

- **Takes:** `examples/survey`, `examples/forever`, `examples/trap`, `examples/triangle`, `examples/composition-layers`, `examples/fonts`, `examples/gallery`, `examples/two-windows`, `examples/permissions`, `examples/files`, `examples/file-escapes`, `examples/network`, `examples/fetch`, `examples/trust`, `examples/clipboard`, `examples/copy-paste`, `examples/menus`, `examples/waft-menus`, `examples/sound`, `examples/tone`, `examples/file-dialogs`, `examples/opener`, `examples/notifications`, `examples/machines`, `examples/file-watching`, `examples/media-players`, `examples/media-assets`, `examples/image-codecs`, `examples/hardware-buffers`, `examples/video-frames`, `examples/cameras`, `examples/environment`, `builtin-apps/notes`, `builtin-apps/video-player`, `examples/input`, `examples/back`, `examples/waft-back`, `examples/waft-image`, `examples/waft-time`, `examples/workers` and `examples/inspect`, built with the pinned toolchain's `wasm32-wasip3` target; and `incompatible.wat` and `imports-inspect.wat`.
- **Provides:** the path of each program, as a `&str` constant, and `CODE_CACHE`, the code cache the tests share for them.
- **Used by:** the engine's tests, `crates/waos/tests/all` and the three binaries beside it, as a dev-dependency of `waos`, and the app's, of `waos-app`.
