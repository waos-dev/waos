# notes

Notes, a library of notes the app keeps itself, as Apple's Notes does, and a text editor of files from anywhere beside it, as an Waft app in WinUI's Fluent look (`waft-winui`). What a person uses to try, in one app, what WaOS gives a program on macOS.

- **The library** is kept in the program's own `/data/notes`, one JSON file to a note, named after its id, holding its text and when it was made, last changed and deleted (`store`). A file to a note means a change writes only that note, and a file spoiled or cut short loses only its note, where one file of every note would be written whole at each key and lose them all. Each file is written safely: in a draft beside it, then renamed onto it. A note's title is its first line that is not blank, or `New Note`; every change is kept as it is typed, so there is no Save and nothing to ask when the window closes.
- **Text files from anywhere** are edited where they are, as TextEdit edits them: File › Open… (⌘O) opens the text files picked in the system's open dialog, a sheet on the window, which asks for files the program may write; and what the system opens Notes with reaches it as WaOS's open requests (`lifecycle`'s `open-requests`), the request that started it among them; a program cannot yet declare the types of file it opens, so the system's file manager does not offer Notes for a text file, and `waos open <file>... --program dev.waos.notes` opens files with it. WaOS mounts each file writable at its own path. The last file opened is shown, with the focus in its text; a file that is not UTF-8 text is said, and not opened. Its text is saved to it as it is typed, safely: a draft in the program's temporary folder, renamed onto it. File › Close File, or the button above it, lets it go from the list, asking first where it holds changes not saved. The files open are kept in `/data/open-files.json` and open again at the next launch, since WaOS keeps every file picked or opened with the program mounted among its grants; one that cannot be read by then is let go, and the window says so.
- **Another app's change** to a file open is never written over unasked. WaOS tells a program nothing when a file changes, so Notes looks, comparing the file's modification time and length with those it last read or wrote: before each save, as the file is shown, and as the app comes back to the front (the lifecycle's resume). A file changed while Notes holds no change of its own is read again; one changed under a change of Notes' is not saved to, and a bar above it offers Save Anyway or Revert; one moved or deleted is not written back unasked, and the bar offers Save Again, at its old path, or Close File. The list marks a file waiting so.
- **The window** is a Fluent navigation view: its pane lists New Note and the notes, most recently changed first, each by its title and, beneath it, when it changed and its line after the title, then a section of the files open, the latest opened first, each by its name and, beneath it, its folder, the one shown selected; its content is the note or the file shown, under a header of its title or name with Delete or Close File, then when the note last changed or where the file is, then its text in a borderless text box filling the rest. It is titled after the note or the file shown, or `Notes`. Above the list, the search field narrows it to the notes, and the files, holding every word typed, a file's name among its text, in any order, whatever their case, and shows the first found when the one shown is not; a list with no notes in it says `No Notes`, or `No Results`. From 600 logical points wide the list is a sidebar beside the note, as on a desktop or a tablet; narrower, as on a phone or in a narrow window, it is a pane over the note, which its toggle opens and which closes as a note is picked. The window opens at 820 by 540 points and is kept at least 320 by 400 (`window.size-limits()`), a phone's width, so both layouts can be seen on a Mac.
- **Dates** are on the user's clock: each moment is moved by how far the user's time zone is from UTC at it (`system`'s `utc-offset`), so a change made late in the evening is listed as that day's; where the system names no time zone, they are UTC's.
- **Deleting** a note (File › Delete, ⌘⌫, or the bin above the note) puts it in Recently Deleted, which the foot of the list opens while it holds any, with how many, and View › Recently Deleted (⌘2) lists, with Back to the notes; there it cannot be changed, and Recover (File › Recover, or the button of the bar above it) puts it back among the notes. A note goes for good at the first launch thirty days after it was deleted, or when deleted again from Recently Deleted once the user agrees. Where the focused text takes ⌘⌫, deleting to the line's start, the note is not deleted.
- **What the window says** is in Fluent's info bars above the note or the file: why a note could not be saved, while the store cannot keep it; that the note shown is deleted; why the file shown is not saved; and what a command did or why it could not, until it is closed or the next change.
- **File:** New Note (⌘N, or the list's first item) opens an empty note with the focus in its text; Open… and Close File, above; Import… copies text files picked in the system's open dialog, a sheet on the window, each into a new note, and opens the last, leaving the files as they are; Export… writes the note shown as plain text where the user picks in the system's save dialog, named after its title, or a copy of the file shown, named as it is, written safely through the program's temporary folder; Close (⌘W) closes the window. **Edit** is the platform's items, which reach the focused text as a native app's do, and Search (⌥⌘F), which moves the focus to the search field, opening the list's pane first where it is closed. **View:** Notes (⌘1) and Recently Deleted (⌘2). **Window** is the platform's items, which make it the menu the system lists the window in.
- **Remind Me in 1 Minute** (File) asks for the notifications permission, as `notifications` says, then has the system show a notification titled with the note shown a minute later, whether or not the program runs. The window says when notifications are denied, or the system cannot show one later. Clicking the notification opens its note in the window brought forward, from the library at a launch the click made too.
- **Quitting** (⌘Q, Quit in the Dock's menu, or closing the window) is agreed to at once while every note and file is saved. Where the store could not keep a note's latest change, or a file could not be written, which a bar above it says while it lasts, the app tries again first, and where it still cannot, or another app changed or removed a file under a change of Notes', asks in a Fluent content dialog whether to quit and lose it. Deleting a note for good asks in one too. Closing the window quits, since WaOS gives a program no way to be reopened with no window.
- **Fonts:** WinUI's controls ask for Selawik, which the app does not bundle, so the system's fonts WaOS gives stand in, as they do for WaOS's own library; the icons are Fluent System Icons, from the font `waft-winui` bundles.

To run it, start the WaOS built from this workspace, which gives a program's window its size limits, then send the program to it:

```sh
cargo waft run -p waos-app      # builds WaOS.app from this workspace, and opens it
cargo waos run -p notes          # builds the program, and runs it in that WaOS
```

- **Takes:** `wasdk-adapter-waft`; Waft's `waft-widgets` (the window, the widgets app and its navigator, the menu bar, the lifecycle's listener, its exit requests and resume, and the text's controller), `waft-winui` (the navigation view, the text boxes, the buttons, the info bars and badges, the content dialog, the tooltips, the theme and its icon font, Fluent System Icons), `waft-embedder` (the file dialogs' options, the open requests, notifications and the editor's text), `waft-services` (quitting, and the menu's keys) and `waft-foundation` (the app and its entities), from crates.io; serde and `serde_json`, for a note's file and the list of files open; `tracing`, for what goes wrong out of the user's sight; `wasdk`, for the entry.
- **Provides:** a component, `target/wasm32-wasip3/debug/notes.wasm`, from `cargo build -p notes --target wasm32-wasip3`, or `target/waos/debug/notes.wasm` from `cargo waos build -p notes`.
- **Used by:** the engine's tests (`crates/waos/tests/all/notes.rs`), through `crates/waos/tests/programs`; whoever runs it in WaOS.
