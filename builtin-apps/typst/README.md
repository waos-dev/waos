# Documents

A live document editor built on [Typst](https://typst.app), the typesetting system: a document is written in Typst's markup on one side and shown as typeset pages on the other, set again as it is typed. Typst's own compiler, renderer and PDF exporter (the `typst`, `typst-render` and `typst-pdf` crates) run inside the program, on a worker of its own, another instance of its code, so the window goes on answering while a document is set, a page drawn or a PDF written; nothing is sent anywhere. The package is `documents`, in `builtin-apps/typst`, since a package cannot share the name of the `typst` crate it depends on.

- **Writing.** The text is edited in a borderless Fluent text box in a fixed-width font, with the system's input methods, selection, undo and the clipboard as any text field has them. Each stretch is drawn as what Typst's parser says it is: headings and strong text bold, code, strings, numbers, math, labels and comments each in a colour, in a light and a dark palette. Tab indents by two spaces. The status bar says the caret's line and column.
- **Pages.** Once typing pauses, the text is set by Typst and the pages are shown one under another on a grey desk, as a PDF viewer shows them. A page is drawn by Typst's renderer as pixels at the screen's density, so it looks as its PDF will; only the pages in sight are drawn, on the worker, one at a time, the next asked for once the last has come, and a page whose content did not change keeps its picture, so typing on one page draws only that page again. The status bar says how many pages there are and how long Typst took.
- **Fonts.** A document is set in Typst's own faces, which the app carries in `fonts/` (Libertinus Serif for text, New Computer Modern Math for formulas, DejaVu Sans Mono for code), and in every face the system offers, as Typst's command-line tool has them: a document that names an installed family is set in it, and a character the carried faces lack, a line of Chinese, falls back to a system face that has it. The worker makes Typst's book of every face as it starts, a system face's entry from the tables `fonts` serves without its file, and opens a face's file through `typeface.open-stream` only once Typst asks for that face, reading it into a buffer of the file's length, as Typst's tool reads it into its own: a few lines of Chinese, for which Typst opens Hei and Apple Color Emoji (183 MiB), leave the worker's memory at 261 MiB and WaOS's process at 247 MiB, where Typst's tool stands at 248 MiB (`../experiments/2026-11-13-typst-system-fonts`). Where a carried face and a system face are alike, Typst takes the carried one, so a document that names no font is set as Typst sets it everywhere. They are the faces Typst's tools bundle, less New Computer Modern's text faces: its regular face is under the GPL, which is why the fonts are files here and not `typst-assets`' `fonts` feature.
- **Problems.** An error or a warning Typst finds is underlined in the text where it is and listed beneath the text with its line, its column and Typst's hints; a click on one selects its place. While the text has an error the last pages that could be set stay, and the status bar says they are not updated.
- **Zoom.** The pages fit the preview's width, or are shown at a percentage from 25% to 800%, where 100% shows a typographic point as a logical pixel: the status bar's − and +, its label, which switches between Fit and 100%, and View › Zoom In (⌘=), Zoom Out (⌘−), Actual Size (⌘0) and Fit Width (⌘9). Zooming keeps the place the pages are scrolled to, and pages wider than the preview scroll sideways.
- **Files.** File › New (⌘N) starts an empty document; Open… (⌘O) opens a `.typ` file picked in the system's open dialog; Save (⌘S) writes it back, asking for a place in the save dialog where it has none; Save As… (⇧⌘S) asks for another. A file is written whole and safely: a draft in the program's temporary folder, renamed onto it. A file the system opens Documents with (`lifecycle`'s open requests) is opened the same way. The window is titled after the document, with `Edited` while it has changes its file does not hold, and before such a document is replaced or the app quits, a dialog asks whether to save it. The document open last opens again at the next launch; a first launch shows a short tour of Typst written in Typst.
- **Export PDF…** (⌘E, or the button) makes the PDF with Typst's exporter and writes it where the user picks in the save dialog. A text with an error is not exported, and the window says so.
- **Files beside the document.** A document may show a picture or include a chapter kept in its folder. WaOS gives a program the file its user opens and nothing else of its folder, so while the text names a file there that cannot be read, a bar above the document offers Give Access…, the system's folder dialog; WaOS keeps the folder among the program's mounts. An untitled document has no folder, and Typst's error says to save it first.
- **A narrow window.** From 720 logical points wide the text is beside its pages; narrower, as on a phone, the window shows one of the two, switched by the Write and Preview selector in the command bar (View › Write, ⌘1, and Preview, ⌘2). The window opens at 1120 by 720 points and is kept at least 340 by 420.
- **The worker.** The window sends the worker each text to set, each page to draw and each PDF to make, as messages in postcard, and the worker answers each in turn: the pages' sizes and what each shows, the problems, a page's pixels, the PDF's bytes. The text is still set only once typing has paused for as long as the last run took, so a long document is not set between two keys; the window does no more than send the text and take in what comes back, under a millisecond for a 23-page document whose page pictures are 8 MB each.
- **Today.** `datetime.today()` is the date on the user's clock, in the time zone the system names (`system`'s `utc-offset`), or at the offset the document names; UTC's where the system names no zone.
- **Keys** are the app's own shortcuts as well as the menu bar's, with Ctrl in place of ⌘ off Apple's systems, so they work where there is no menu bar.

## What it does not do

- **The system's hidden faces.** The families are those the system offers to apps (249 on this Mac); Typst's tool scans the font folders' files, the system's hidden faces among them (453).
- **Packages.** `#import "@preview/…"` answers an error: packages are downloaded from Typst's package server, which the app does not do.
- **File associations.** A package cannot yet declare the types of file its program opens, so the system's file manager does not offer Documents for a `.typ`.
- **A caret that stays put at a line's end.** Waft draws a caret at the end of a line that is not the text's last at the start of the next line, and where the next line is empty, at the end of the text, scrolling there: typing at the end of a paragraph that a blank line follows makes the editor jump to the end of the text. It is Waft's text box, so Notes has it too; typing anywhere else in a line is not affected.
- **Line numbers, unwrapped lines, find and replace.** Waft's multi-line text box always wraps, and offers no gutter.
- **Zooming by pinch or ⌘-scroll**, and a click on a page that goes to its place in the text.

## Running it

The compiler is slow unoptimized, so run the release build:

```sh
cargo waos run -p documents --release     # builds the program, and runs it in the WaOS on this machine
cargo test -p documents                   # the logic's tests, on this machine
```

The first run of a build takes WaOS a while before the window shows: the component holds Typst, its fonts and Waft (about 65 MB), and WaOS compiles all of it for the machine first.

- **Takes:** `waft-embedder-wasdk` and `wasdk`, the system's fonts through its `fonts`; Waft's `waft` (the window, the widgets, entities, the text's controller, the file dialogs' options, open requests and pixels made into an image), `waft-winui` (the text box, buttons, selector bar, info bars, content dialog, tooltips, the theme and its icon font), `waft-services` (keys, and quitting) and `waft-rendering` (how a row is hit); `typst`, `typst-layout`, `typst-render` and `typst-pdf`, Apache-2.0; `serde`, `postcard` and `serde_bytes`, for the messages to and from the worker, and `futures`, for the queue of the window's requests; the font files in `fonts/`, each under the terms `fonts/LICENSES.txt` gives (Libertinus Serif the SIL Open Font License, New Computer Modern Math the GUST Font License, DejaVu Sans Mono Bitstream Vera's and DejaVu's).
- **Provides:** a component, `target/waos/release/documents.wasm`, from `cargo waos build -p documents --release`.
- **Used by:** whoever runs it in WaOS.
