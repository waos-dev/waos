# Build an app on WaOS

Do each step yourself; ask the user only where a step says so.

1. **Tools:** WaOS uses two Rust toolchains through rustup: latest **stable** Rust (1.85 at least; ask the user before installing rustup, or run `rustup update stable`), and the nightly a program pins. WaOS and its command come in one install: `curl -fsSL https://waos.app/install.sh | sh` on macOS or Linux, `irm https://waos.app/install.ps1 | iex` in PowerShell on Windows. It installs the newest WaOS (on Linux one that runs without a display too) and puts its command, `waos`, on the PATH; ask the user before running it. Where WaOS can't be installed, `cargo install waos-cli` installs the command alone, and building and packaging still work. Each program created by `waos new` includes a `rust-toolchain.toml` pinning the **nightly** toolchain and `wasm32-wasip3` target, which rustup fetches automatically on the first build — do not override it globally.
2. **Make:** `waos new <name>`, a WinUI app that works on desktops and phones; `--template cupertino` only for an app meant for phones alone. Edit `src/main.rs`.
3. **Look things up:** `waos docs` prints the map of WaOS's docs, for the version your app builds with, `waos docs <page>` one page, and `waos docs --search <text>` the lines that hold the text. Read `waft` (how an app is put together: logic, state and UI), `concepts` (which crate holds what, and the owned-for-async WIT rule) and the page of each thing the app uses, before writing it. The same pages are at https://waos.app/docs, Waft's full UI framework docs are at https://waft.rs/docs, and the API on docs.rs: `wasdk`, `waft`, `waft-winui`, `waft-cupertino`, `waft-material`, `waft-markdown`.
4. **Icon:** replace `icon.png` with one thing that says what the app does, drawn with care: few colours and one accent, light from above, soft shading, on a quiet background. Aim for the finish of Apple's own icons, and draw it to sit beside WaOS's own apps in its library (they are at https://waos.app/docs/icons); not a line symbol, a letter or a photo. It is 1024 × 1024 and fills the whole square, with no rounded corners, margin, transparency or shadow of its own; WaOS cuts each system's shape, so nothing depends on the edge and what matters stays in the middle two thirds.
5. **Build:** `waos build` until it compiles. A dependency with C code (`libsqlite3-sys`, `zstd-sys`, `onig`, `ring`, `psm`/`stacker`, tree-sitter) needs a wasi-sdk on LLVM 23, wasi-sdk 34 or later: `waos docs start` says how to point the build at it; ask the user before downloading one, or pick a pure-Rust alternative.
6. **Ship:** `waos package`, which writes a signed `.wapk` under `target/waos/`.

## Trying it, when you want to see it work

`waos docs tools` has every command, with its units and limits.

- **Run:** `waos run`, left running; it prints the app's output and panics. It needs WaOS from step 1; on Linux without a display it starts WaOS headless by itself. An app opened from WaOS itself prints into WaOS's log instead; on Android, which `waos` does not reach, that is `adb logcat -s waos`.
- **Look:** `waos ui screenshot`, then read the PNG.
- **Resize:** `waos ui resize --to 390x844` sizes the window to a phone's, in points (a screenshot's pixels over the window's scale), to see the layout at that width; it prints the size the window took.
- **Answer ahead:** `waos settings set camera allow` (or `simulated`, a test pattern from WaOS on macOS and Android, and `microphone simulated`, a quiet beep), `waos settings set save-file /tmp/out.pdf`, `waos settings set machine this-computer`, so a run never stops at a question WaOS asks its user; `waos settings` lists every row, and a run on Ask says on its terminal what WaOS is asking.
- **Act:** `waos ui tap --at x,y`, `waos ui press --at x,y` (held a second), `waos ui drag --from x,y --to x,y` (10 moves over 300 ms), `waos ui type "…"`, `waos ui key cmd+s`, `waos ui scroll --at x,y --by dx,dy`, in the screenshot's pixels. Each returns once the input is handed to the app; take a screenshot to see what it drew, and another if it has not drawn yet.
