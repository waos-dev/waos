---
title: Start
description: From nothing to a running app, in five steps.
---

1. **Install WaOS and its command,** in one step: `curl -fsSL https://waos.app/install.sh | sh` on macOS (Apple Silicon) or Linux, `irm https://waos.app/install.ps1 | iex` in PowerShell on Windows. It installs the newest WaOS and puts its command, `waos`, on the PATH; on Linux WaOS also runs without a display. For a phone, [download WaOS for Android](/download/android). `cargo install waos-cli` installs the command alone, for building and packaging where WaOS isn't needed.
2. **Rust:** latest **stable** Rust (1.85 at least, via [rustup](https://rustup.rs) and `rustup update stable`) builds with the command, while each program's `rust-toolchain.toml` pins the **nightly** toolchain with the `wasm32-wasip3` target that rustup fetches automatically on the first build.
3. **Make a program:** `waos new hello`, a WinUI app, which works on a desktop and on a phone. For an app meant for phones alone, add `--template cupertino`. Its `icon.png` is a placeholder: draw one to sit beside [WaOS's own apps](/docs/icons).
4. **Run it:** `cd hello && waos run`, which shows what it prints; a program opened from WaOS prints into WaOS's log instead.
5. **Package it:** `waos package`, which writes a signed `.wapk`.

A program that depends on C-compiling crates (such as `libsqlite3-sys`, `zstd-sys`, `onig`, `ring`, `psm`/`stacker`, or tree-sitter grammars) builds that C code with a [wasi-sdk](https://github.com/WebAssembly/wasi-sdk/releases) on LLVM 23, wasi-sdk 34 or later: set `CC_wasm32_wasip3` and `AR_wasm32_wasip3` to its `clang` and `llvm-ar`, and `CFLAGS_wasm32_wasip3` to `--sysroot=<wasi-sdk>/share/wasi-sysroot`. An older clang fails at the link with "object file uses globals for thread context, but --cooperative-threading was specified". Prefer pure-Rust crates where available to avoid needing a C cross-compiler.

`waos docs` prints these docs for the version your app builds with, downloaded once from that release and read offline after: their map, `waos docs <page>` a page, and `waos docs skill install` writes them as a skill for the agent that writes the app ([The tools](/docs/tools)).
