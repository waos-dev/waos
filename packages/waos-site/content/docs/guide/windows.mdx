---
title: Windows
description: Ask for a window, title it, and limit its size.
---

A program's windows on a desktop: each a real window of the system's, holding one view. An installed program's windows are an app of its own, with its name and icon in the Dock, the taskbar or the dock; on Windows and Linux a program never installed shows under WaOS's. A program asks for one with a title and size, and can limit how small or large the user makes it.

## With wasdk

```rust
let config = WindowConfig::new();
config.set_title("Notes");
// the window's view arrives on views::view_changes()
views::request_view(&config, None)?;
// once it has arrived:
// window.size_limits().map(|limits| limits.set_min_size(Some(Size { width: 320.0, height: 400.0 })));
```

## With Waft

For a single window, pass the root widget to `run_app_with`:

```rust
let window = WindowConfig {
    title: "Notes".into(),
    size: [820.0, 540.0],
    ..WindowConfig::default()
};
run_app_with(app, notes_app(), window);
// in a widget:
let window = View::maybe_of(app, context).and_then(|view| view.window());
if let Some(limits) = window.as_ref().and_then(|window| window.size_limits()) {
    limits.set_min_size(Some(Size::new(320.0, 400.0)));
}
```

> `run_app_with` builds its widget only in views whose `initial_data().is_none()`. If you open additional windows by calling `app.platform().request_view(config, Some(tag))`, those secondary views will stay blank under `run_app_with`.

For two or more windows, ask for each window with `app.platform().request_view` and build every view from its `initial_data()` inside a `MultiViewApp` started with `run_widget`:

```rust
use std::rc::Rc;

use waft::*;
use waft_winui::*;

fn start(app: &mut App) {
    for (tag, title) in [("editor", "Notes"), ("preview", "Preview")] {
        let config = WindowConfig {
            title: title.into(),
            size: [640.0, 480.0],
            ..WindowConfig::default()
        };
        let _ = app.platform().request_view(config, Some(tag.into()));
    }
    let windows = MultiViewApp::new(|_app, view| match view.initial_data() {
        Some("editor") => Some(FluentApp::new().debug_show_checked_mode_banner(false).home(Editor).into_widget()),
        Some("preview") => Some(FluentApp::new().debug_show_checked_mode_banner(false).home(Preview).into_widget()),
        _ => None,
    })
    .on_close_requested(Rc::new(|_app, view| {
        if let Some(window) = view.window() {
            window.close();
        }
    }));
    run_widget(app, windows.into_widget());
}
```

## Where it's missing

On Android each window a program asks for is a task of its own, a card in Recents with the window's title and the program's icon, and the program ends with its last one, as on a desktop. Where the user has WaOS show programs in its own tabs, the program is given its tab's view, and asking for a window is refused. `size-limits` is none where users don't resize windows.
