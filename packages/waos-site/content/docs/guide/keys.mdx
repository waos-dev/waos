---
title: Keys
description: Hear the keyboard's keys, by what they mean and by where they are.
---

A view's keys arrive while it has the keyboard's focus, each as Flutter's `KeyData` has it: down, repeat or up, its `logical` key, what it means under the user's layout (a character key's lower-case code point, else Flutter's number for the named key), its `physical` key, where it is on the keyboard (its USB HID usage), and the text it typed. `wasdk::keys` names both, Flutter's names, so a program compares with names rather than numbers it might write wrong. Each key comes with a reply: the program says whether it handled it, and one it leaves goes on to the platform's menus, as ⌘C left unhandled reaches Edit's Copy.

## With wasdk

```rust
use wasdk::keys::{logical, physical};

// ViewEvent::Key arrives on view.events()
let KeyInput { event, reply } = key;
let pressed = event.kind != KeyKind::Up;
if pressed && event.logical == logical::ARROW_LEFT {
    previous_page();
}
// by where it is, whatever the layout: W, as WASD moves
let forward = pressed && event.physical == physical::KEY_W;
reply.handled(true);
```

A key names no modifiers, as `KeyData` names none: a program keeps which are held from the modifier keys it is sent, `logical::SHIFT_LEFT`, `logical::SHIFT_RIGHT` and the like, never `logical::SHIFT`, which stands for either in Flutter's maps and is never sent. A modifier that changed while the program was not told, as around a click in another window, arrives as a `synthesized` key before the pointer event that showed it. Model Viewer keeps egui's modifiers this way.

## With Waft

Keys are Flutter's: a key goes to the widget with the focus and up through its ancestors, named by `LogicalKeyboardKey`, with `Shortcuts`, `Actions` and `CallbackShortcuts` for commands ([Keys and shortcuts](/docs/frameworks/waft#keys-and-shortcuts)).

## Where it's missing

A key the program leaves goes on to the menu bar where the platform has one, macOS's; on Windows and Linux it goes no further. A dropped reply is a key not handled.
