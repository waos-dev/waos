---
title: Media players
description: Play video and sound with the system's player.
---

Media played by the system's own player: a file inside the program, or an `http` or `https` link, which the system fetches itself. The system plays its sound and draws its picture, on a composition layer the program places, or into a frame reader whose frames the program draws itself. The player's state, the subtitles to draw and the media's tags come on streams; its position is read when the program needs it, never sent on a timer, and its tracks are picked by their ids in its state.

## With wasdk

```rust
// players: media_players::get_media_players()
let player = players.open("https://example.com/talk.mp4");
let layer = views::get_compositor().map(|compositor| compositor.make_layer(false));
if let Some(layer) = &layer {
    // placed with view.set_layers
    player.set_video_output(Some(&VideoOutput::Layer(layer)));
}
player.play();
// loading, ready or failed; paused, waiting or playing
let mut states = player.state_changes();
// the subtitles to draw, as the media styles them
let mut cues = player.cue_changes();
```

## With Waft

```rust
// or a picked file's PickedFile::url()
let player = Player::new(app, "https://example.com/talk.mp4")?;
player.play(app);
// in a widget: the picture, its subtitles over it
PlayerView::new(player)
```
A `PlayerView` draws the subtitles in the user's caption style. A `VideoFrameView` draws a reader's frames instead, for a video under effects a layer cannot take.

## Where it's missing

`get-media-players` is none where the system has no players, and Waft's `Player::new` none with it. A link passes the program's network rules first; one they refuse, or a path outside the program's files, gives a player that failed with `refused`. Where the system has no compositor, the picture goes to a frame reader (`get-video-frame-readers`, none where the system hands out no frames), or nowhere, and the sound plays alone. The system draws no subtitles: the program draws the cues, merging in the user's caption style (`wasdk:media/caption-settings`).
